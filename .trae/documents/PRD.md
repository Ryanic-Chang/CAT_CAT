## 1. 产品概述
CAT_CAT是一款可爱的Chrome浏览器插件，以像素风格的猫咪形象作为交互界面。通过悬浮在网页上的猫咪助手，用户可以快速管理书签、获取AI页面总结和联想推荐，同时享受有趣的互动体验和贴心的健康提醒。

目标用户：需要高效浏览体验、喜欢可爱元素、注重健康上网的Chrome用户。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 使用基础功能（书签管理、健康提醒、互动动画） |
| AI用户 | 设置API密钥 | 额外使用AI总结和联想功能 |

### 2.2 功能模块
CAT_CAT插件包含以下核心功能：
1. **猫咪悬浮窗**：可爱的像素猫咪形象，支持拖拽定位和动画效果
2. **书签管理**：快速添加当前页面到书签，支持选择/创建文件夹，打开指定书签
3. **AI智能助手**：页面内容总结（可下载）和智能联想推荐相关链接
4. **健康提醒**：浏览超时提醒休息功能
5. **互动娱乐**：猫咪对话、动画彩蛋、随机拒绝互动

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|-------------|
| 悬浮窗主界面 | 猫咪形象 | 显示像素风格猫咪，支持hover/click交互，显示可爱对话框 |
| 悬浮窗主界面 | 功能菜单 | 悬停时显示功能选项：书签管理、AI助手、健康设置 |
| 书签管理弹窗 | 添加书签 | 将当前页面添加到书签，支持选择现有文件夹或新建文件夹 |
| 书签管理弹窗 | 打开书签 | 浏览和打开已保存的书签，支持搜索和分类 |
| AI助手弹窗 | 页面总结 | 调用Qwen API分析页面内容，生成可下载的总结报告 |
| AI助手弹窗 | 页面联想 | 基于页面内容推荐相关链接和资源 |
| 设置页面 | API配置 | 配置Qwen API密钥和相关参数 |
| 设置页面 | 健康提醒 | 设置浏览时间限制和休息提醒间隔 |
| 设置页面 | 外观设置 | 调整猫咪大小、位置、动画频率等 |

## 3. 核心流程

### 主要用户操作流程：
1. **首次使用**：安装插件 → 猫咪自动出现在页面 → 点击猫咪进行设置 → 配置API密钥（可选）
2. **日常使用**：悬停猫咪 → 选择功能 → 执行操作 → 查看猫咪反馈
3. **书签管理**：悬停猫咪 → 选择"添加书签" → 选择/创建文件夹 → 确认添加
4. **AI功能使用**：悬停猫咪 → 选择"AI助手" → 选择总结或联想 → 获取结果

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：暖橙色（#FF8C42）和米白色（#FFF8F3）
- **辅助色**：粉色（#FFB6C1）和深灰色（#4A4A4A）
- **按钮样式**：圆润的3D效果，悬停时有轻微弹跳动画
- **字体**：圆体或无衬线字体，主要文字14-16px，标题18-20px
- **图标风格**：像素风格，16x16或32x32像素艺术

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 悬浮窗主界面 | 猫咪形象 | 32x32像素猫咪，支持眨眼、摇尾巴动画，对话框采用气泡样式 |
| 功能菜单 | 菜单项 | 圆形按钮排列，图标+文字，悬停放大效果 |
| 书签弹窗 | 文件夹选择 | 树形结构展示书签文件夹，支持拖拽和新建 |
| AI结果弹窗 | 内容展示 | 卡片式布局，支持复制和下载按钮 |
| 设置页面 | 配置项 | 表单式布局，开关按钮，输入框带验证提示 |

### 4.3 响应式设计
- 桌面端优先设计，猫咪悬浮窗可自由拖拽到屏幕任意位置
- 适配不同网页布局，自动避开主要内容区域
- 支持触摸设备的基本交互（点击代替悬停）

### 4.4 动画效果
- **猫咪动画**：idle时的眨眼、摇尾巴、伸懒腰
- **交互反馈**：点击时的弹跳、对话框弹出动画
- **彩蛋动画**：拒绝服务时的扭头、捂脸动作
- **过渡效果**：菜单展开/收起的平滑过渡

## 5. 技术实现要求

### 5.1 性能要求
- 插件加载时间 < 500ms
- 猫咪动画帧率 > 30fps
- API调用超时设置 30s
- 内存占用 < 50MB

### 5.2 兼容性要求
- Chrome 88+ 支持
- 支持主流网站（不干扰原有功能）
- 适配深色/浅色主题网页

### 5.3 安全要求
- API密钥本地加密存储
- 不收集用户浏览数据
- 权限最小化原则
