# ? CAT_CAT — 浏览器里的猫猫助手

 一个可爱、实用、会“主动互动”的猫猫悬浮助手，帮你快速收藏书签、智能总结页面，并提醒你适时休息。让浏览更高效更有趣！

## ? 名字与灵感（CAT_CAT）

- 第一个 **CAT**：指代“猫猫”本体，代表陪伴与轻松互动 ?
- 第二个 **CAT**：来源于 **Linux 的 `cat` 命令**，有“查看内容”的含义，寓意用“猫猫”的方式帮助你快速查看与理解网页 ?
- **CAT_CAT 像颜文字表情**（如 `=^_^=` 的感觉），既可爱又易记，这是名字的灵感来源 ?

## ? 特性亮点

- ? **悬浮猫猫**：支持拖拽、悬停动画、点击互动，对话气泡更亲切。
- ? **快速书签**：一键保存当前页面到指定文件夹，支持创建新文件夹与容错保存。
- ? **AI 页面总结**：调用 Qwen 模型总结当前页面并给出相关链接，支持导出文本。
- ? **休息提醒**：可以开启定时提醒，并在启用时弹窗设置时间；支持随时开关提醒。
- ? **随机互动**：猫猫会在空闲时随机弹出轻量提示，鼓励你使用功能，且不打扰当前操作。
- ? **精致图标**：工具栏图标采用“橙色悬浮球 + 白色猫猫”的视觉，清晰醒目。

## ? 安装与构建

### 环境要求
- Node.js 16+
- npm（或 yarn / pnpm）

### 安装依赖
- 在项目根目录执行：
```bash
npm install
```

### 生产构建
- 生成 `dist` 目录：
```bash
npm run build
```
- 构建包含：Popup、Content Script、Background 三个部分的独立产物。

### 加载到 Chrome
- 打开 `chrome://extensions/`
- 开启右上角 **开发者模式**
- 点击 **加载已解压的扩展程序**，选择项目中的 `dist` 目录
- 在扩展菜单中将 CAT_CAT **固定**到工具栏

## ? 使用指南

- **设置 API Key**（Popup 页面）：
  - 打开工具栏图标 → 输入并保存 Qwen API Key（仅此一项设置）。
- **悬浮菜单**（页面右下角猫猫）：
  - 悬停显示菜单：书签 / AI 总结 / 提醒开关
  - 书签：弹出文件夹选择，支持新建，保存成功会提示
  - AI 总结：提取页面可读文本，调用模型返回总结与关联链接
  - 提醒开关：从关闭到开启时会弹出“设置提醒时间”的对话框（单位分钟）
- **随机互动**：猫猫会在空闲状态下每 25–60 秒随机给出轻量提示，避免与当前气泡、菜单、提醒冲突

## ?? 权限与安全

- `bookmarks`：用于读取/创建书签及文件夹
- `storage`：保存配置（如 API Key、提醒开关与间隔）
- `alarms`：用于周期性提醒（Manifest V3 必需）
- `activeTab` / `scripting`：与当前活动标签页交互（如注入内容脚本）
- `host_permissions`：
  - `https://dashscope.aliyuncs.com/*`（Qwen 兼容模式 API）

## ? AI 总结与关联链接

- 后台脚本会将页面文本片段化处理（最长 5000 字符），构建提示词并调用 Qwen 模型。
- 返回结果优先解析为 JSON；若模型未严格遵守格式，自动降级为纯文本并不报错。
- 在对话框中展示总结与关联链接，可一键下载为 `page-summary.txt`。

## ? 书签保存逻辑

- 文件夹列表为 **扁平结构**（带层级深度），渲染性能更好。
- 保存时会验证所选文件夹是否存在；若无效，将自动选择根下第一个合法文件夹进行容错保存。
- 弹窗层级与遮罩交互已修复，避免“界面半透明不可点击”的问题。

## ? 休息提醒（Health Reminder）

- 工具栏不再提供提醒设置；**从悬浮菜单开启时**弹出设置对话框。
- 背景脚本使用 `chrome.alarms` 定时触发，向当前活动标签发送提醒消息。
- 提示弹框提供“确定休息”与“暂时忽略”两个按钮，避免打断工作流。

## ? 图标与生成脚本

- 源图：`public/icon.svg`
- 生成 PNG：
```bash
npm run icons
```
- 输出：`public/icons/icon-{16,32,48,128}.png`
- Manifest 已配置多尺寸 PNG，确保在所有 Chrome 版本显示一致。

## ? 主要目录结构

```
src/
  components/           # 组件（猫猫、菜单、对话框等）
  content/              # 内容脚本入口
  background/           # 后台 Service Worker
  popup/                # 扩展 Popup 设置页
public/
  manifest.json         # 扩展清单（MV3）
  icon.svg              # 图标源 SVG
  icons/                # 生成的 PNG 图标
scripts/
  generate-icons.mjs    # 将 SVG 生成多尺寸 PNG
```

## ? 调试与常见问题

- 书签弹窗半透明或无法点击：已修复遮罩与内容层级；刷新扩展后生效。
- 工具栏图标显示拼图：需固定扩展，或确保使用的是 **PNG** 图标并刷新扩展。
- AI 总结失败：检查 API Key 是否正确；网络问题时会显示错误消息。
